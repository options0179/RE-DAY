# Agent 과거 추출·전환 기록

아래 파일은 이전 Copilot Studio Agent를 추출하고 Gemini/MCP 전환을 계획·검토하던 시기의 기록이다. 해당 시점의 코드 구조와 상태를 담고 있으며 현재 Java/Spring Boot 런타임 설명이 아니다.

- `agent-manifest.md`: 당시 Copilot Studio 화면에서 확인한 구성과 차이
- `copilot-studio-api-connect-phase1.md`, `copilot-studio-api-connect-phase2.md`: 당시 HTTP action 연결 시도
- `gemini-migration-decision.md`, `migration-progress.md`: 이전 전환 선택과 진행 상태
- `implementation-gaps.md`: 이전 코드베이스의 Agent 연결·품질 문제
- `mcp.md`: 이전 MCP 연결 문서
- `process-improvement.md`: 당시 작업 진행 방식의 회고

현재 런타임에서 읽는 프롬프트는 [`../../agent/`](../../agent/)에 별도로 둔다.
